# Implementation

## Steps

### I-S01: 建立跨 Agent 的列表状态模型

在协议与 Web 边界明确统一状态、可选 Agent 原生状态、设备来源、父子关系和可交互能力，保证现有 GitHub Copilot 接入兼容。

### I-S02: 实现预定义筛选与层级派生

实现动态状态 badge、默认可见范围、视图选项、搜索匹配和保留父级上下文的树形排序，并让设备分组复用同一派生结果。

### I-S03: 更新列表呈现与响应式交互

以紧凑树形行替换现有弱缩进表达，补齐折叠、选中、键盘与移动端行为，并保持 Session 选择和 URL 导航不变。

## Acceptance criteria

### I-AC01: 筛选语义一致

自动化测试证明统一状态映射、按需 badge 计数、默认隐藏状态和组合搜索在不同 Agent/设备数据下符合契约。

### I-AC02: 层级上下文稳定

自动化测试证明正常、搜索和状态筛选场景都保持父子顺序，命中 subsession 时显示弱化父级，循环或缺失父级仍能安全降级。

### I-AC03: 列表体验跨视口可用

浏览器验证证明桌面窄侧栏与移动端均无横向溢出，树形控制可通过键盘操作，选择 Session、返回列表和 URL 历史行为保持正常。
