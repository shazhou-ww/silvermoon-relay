# Implementation

## Steps

### I-S01: 建立消息流滚动状态

为消息容器增加稳定引用与“接近底部”判定，区分首次历史加载、Session 切换、用户主动滚动和后续事件追加，避免异步布局导致定位过早。

### I-S02: 增加返回最新消息控件

在消息区与输入区之间增加浮动控件及响应式样式；仅在用户离开底部时显示，激活后按动态效果偏好平滑或即时定位到底部。

### I-S03: 覆盖滚动交互回归

为初始加载、Session 切换、底部自动跟随、历史阅读保护、返回按钮、事件筛选和窄屏行为补充可重复验证。

## Acceptance criteria

### I-AC01: 最新内容定位可靠

自动化测试与浏览器检查证明：长 Session 首次加载和切换后定位到底部；用户仍在底部时，追加事件后继续显示最新内容。

### I-AC02: 历史阅读不被打断

自动化测试证明：用户离开底部后追加事件、轮询刷新和工具消息筛选不会强制改变其阅读位置。

### I-AC03: 返回控件可访问且响应式

桌面与窄屏浏览器检查证明：浮动控件仅在需要时出现，可通过指针和键盘激活，具有明确可访问名称，且不会遮挡消息或输入区。
