# 让消息流始终可回到最新位置

## 问题

打开或切换到已有 Session 时，消息流不会定位到最新内容；用户向上浏览历史后，也缺少快速回到底部的入口。长会话因此容易让人误以为没有新消息，恢复到当前进度也很费力。

## 结果

Session 的首批历史记录完成布局后自动显示最底部；用户停留在底部时，新消息继续自动跟随。用户主动向上滚动后保留阅读位置，并显示一个可一键回到最新消息的浮动按钮。说明性对比见 [消息流滚动 UI 评审](./ui-review/index.html)。

## 边界

- 自动滚动只作用于当前 Session 的消息容器，不改变事件顺序、筛选、同步或输入框行为。
- 用户浏览历史时不得被新事件强制拉回底部；返回按钮需支持键盘、明确的无障碍名称和窄屏布局。
- 桌面与移动视图使用同一交互语义，并尊重系统的减少动态效果偏好。

## 验收标准

- 打开或切换到包含历史记录的 Session 后，首屏直接显示最新的可见事件和输入区。
- 位于底部时新增事件保持可见；离开底部后新增事件不改变当前阅读位置。
- 离开底部时出现浮动的“回到最新消息”控件，激活后定位到底部并立即隐藏。
