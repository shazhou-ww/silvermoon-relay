# Deployment

## Steps

### D-S01: 验证真实 Agent 会话

在连接真实 VS Code Agent Host 的非生产环境回放并实时运行包含 Markdown、多个工具、失败、等待和重连的代表性 Session，收集顺序、状态与响应式界面证据。

### D-S02: 渐进发布并观察兼容性

按现有 Web 发布流程推出新渲染路径，观察旧会话、活动会话和 Connector 版本组合；保留可执行的回退方式，直到兼容性证据稳定。

## Acceptance criteria

### D-AC01: 真实会话顺序与状态一致

部署证据中的实时和历史会话与 Agent Host 原始状态逐项对应，没有丢失、重复、重排或永久停留在进行中；通过带时间戳的场景矩阵和界面记录证明。

### D-AC02: 发布无兼容性回归

发布观察期内既有会话仍可阅读和继续，消息加载与发送错误率无材料性回归，且回退演练能恢复原渲染路径；通过运行指标、抽样会话和回退记录证明。
